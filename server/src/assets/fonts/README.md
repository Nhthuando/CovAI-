# Report fonts

Noto Sans Regular and Bold are embedded in exported PDFs to support Vietnamese and Latin text consistently on Windows and Linux.

Original source: [Noto Sans static fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans). Both files are unmodified. Copyright 2018 The Noto Project Authors. The SIL Open Font License 1.1 is included in `OFL.txt`.

The font files ship with the server; report generation makes no network requests for fonts.
