# Project Structure Analyzer usability protocol

Recruit ten representative developers. Give each the same completed analysis and ask them to find a selected file's role, direct dependencies, direct dependents, and exported functions. Record task completion and elapsed time; the acceptance target is at least nine participants completing all four tasks in five minutes. Record blockers, selected snapshot, and any diagnostic that prevented discovery.
