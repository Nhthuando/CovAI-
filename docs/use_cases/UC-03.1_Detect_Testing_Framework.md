# Use Case Specification: UC-03.1 Detect Testing Framework

## 1. Overview
- **Use Case ID:** UC-03.1
- **Use Case Name:** Detect Testing Framework
- **Created by:** Nguyễn Duy Quý
- **Date Created:** Sep 15, 2026
- **Last updated by:** Nguyễn Duy Quý
- **Date last updated:** Sep 17, 2026
- **Actors:** Developer / QA / AI Engineer
- **Brief Description:** The system identifies the testing framework used by a project to enable automated test execution.
- **Goal:** Identify supported testing frameworks (Jest, Vitest, Supertest, Playwright, Cypress) within the project source code.
- **Trigger:** User initiates framework detection via the testing interface.
- **Pre-conditions:** User authenticated; project source code available in COVAI system.
- **Post-conditions:** Detected framework is displayed and stored for subsequent test execution.

## 2. Main Flow
1. **User:** Opens testing function of the project.
2. **System:** Displays testing interface and framework detection option.
3. **User:** Selects "Detect Testing Framework".
4. **System:** Analyzes project source code and configuration files.
5. **System:** Identifies the testing framework.
6. **System:** Displays the detected framework.
7. **User:** Continues with the testing process.

## 3. Alternative Flows
### Alternative Flow 1: Supported Framework Detected
1. **System:** Detects one of the supported frameworks (Jest, Vitest, Supertest, Playwright, or Cypress).
2. **System:** Displays result and enables continuation of testing process.

### Alternative Flow 2: User Aborts
1. **User:** Views detected framework.
2. **User:** Returns to project interface without starting test execution.

## 4. Exception Flows
### Exception Flow 1: No Supported Framework Detected
1. **System:** Fails to identify a supported framework.
2. **System:** Displays: "No supported testing framework was detected."
3. **User:** Returns to testing interface.

### Exception Flow 2: Source Code Unavailable
1. **System:** Validates project source code availability.
2. **System:** Detects unavailability.
3. **System:** Displays: "Project source code is unavailable. Framework detection cannot be performed."

### Exception Flow 3: Detection Failure
1. **System:** Encounters error during analysis.
2. **System:** Displays: "Framework detection failed. Please try again later."
3. **User:** Retries detection.

## 5. Business Rules
- Supported frameworks: Jest, Vitest, Supertest, Playwright, Cypress.
